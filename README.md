# Demon — Infernal Sanctum

An interactive infernal scene built with React Three Fiber, Drei and Three.js.

**[Live demo →](https://crapthings.github.io/noamblight/)**

- Flowing lava across Simplex + FBM terrain
- Volumetric fire, drifting fog and rising embers
- Burning 3D lettering and a slowly rotating ritual seal
- Wall mural with a giant demon shadow

Drag to orbit. Scroll or pinch to zoom. Best viewed on a desktop browser with WebGL2 support.

## Run locally

Node.js 24 · pnpm 12.4.1

```sh
pnpm install --frozen-lockfile --strict-peer-dependencies=false
pnpm dev
```

Pushes to `main` automatically deploy to GitHub Pages.
